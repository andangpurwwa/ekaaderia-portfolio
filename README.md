# Eka Aderia Ningrum — Professional Portfolio Website

A responsive static portfolio website built from the provided CV with a premium white-and-blue visual direction. The revised interface focuses on recruiter-friendly scanning, modern editorial spacing, glass effects, subtle 3D depth, smooth reveal animations, interactive project cards, and strong mobile responsiveness.

## Files
- `index.html` — main portfolio content
- `styles.css` — premium responsive UI, layout, colors, glass effects, hover states, and animation
- `script.js` — navigation state, scroll progress, reveal animation, animated counters, timeline filtering, spotlight interactions, and subtle hero parallax
- `assets/Eka-Aderia-Ningrum-CV.pdf` — downloadable CV

## Run locally
Open `index.html` directly, or run a local static server in this folder.

Example:
```bash
python -m http.server 8080
```
Then open `http://localhost:8080`.

## Notes
The website is frontend-only and intentionally lightweight. The email contact button uses `mailto:` so no backend is required.
